# 🔵 Optional 단계 트리거 규칙

> Optional 단계 트리거 및 Phase 결정 포인트 형식의 권위 있는 출처. Full / Revision / Custom 모드 규칙 파일에 의해 로드됩니다.

이 파일은 Optional 단계의 트리거 조건을 중앙화하여 각 모드 규칙 파일이 이를 중복 정의하지 않도록 합니다.

---

## 1. Core vs Optional 정의

- **Core(코어)**: 항상 실행됩니다. 사용자가 명시적으로 오버라이드하지 않는 한 건너뛸 수 없습니다.
- **Optional(옵션)**: 적어도 하나의 트리거 조건이 충족되었을 때에만 실행됩니다. 사용자는 언제든지 강제 포함 또는 강제 건너뛰기를 할 수 있습니다.

---

## 2. Persona-Journey 번들링 규칙 (전역)

**Journey Map은 Persona의 자연스러운 확장입니다: Persona는 Who(누구)를 정의하고, Journey Map은 Who가 경험하는 여정을 묘사합니다. Persona 단계가 완료된 후 Journey Map은 기본 ON으로 포함되며, 상황이 진정으로 매핑하기에는 너무 단순한 경우에만 스킵됩니다.**

> ⚠️ 이 규칙은 "0-to-1에는 Journey Map이 필요 없다"는 이전의 잘못된 가정을 바로잡습니다. 실제로는 그 반대입니다 — Teresa Torres (Continuous Discovery), Indi Young (Mental Models), Amazon Working Backwards 프로세스는 모두 Journey Map을 0-to-1 단계의 필수 요소로 취급합니다. 새로운 경험이 어떻게 설계될지를 형성하기 때문입니다. 관련 변수는 **사용자의 Job이 여러 단계에 걸쳐 있는지 여부**이지, 제품이 이미 존재하는지가 아닙니다.

### 스킵 조건 (기본 ON; 다음 중 하나라도 충족될 때만 스킵)

1. **단일 상호작용 지점** — Job이 단일 API 호출, 단일 버튼, 순수 백엔드 서비스 또는 순수 설정 도구로 해결됨 (다단계 플로우가 존재하지 않음)
2. **플로우가 1–2 단계뿐** — 전체 사용자 플로우가 너무 짧아서 Journey Map이 의미 있는 단계 전환 없는 단순 목록으로 변질됨
3. **사용자가 명시적으로 스킵 요청** — 예: "Journey Map 스킵", "我不需要 Journey Map"

### 스킵 시 동작

조용히 스킵하지 말고 결정을 사용자에게 드러내세요:

> "Persona가 완성되었습니다. 현재 컨텍스트([단일 상호작용 지점 / 플로우가 N 단계뿐])를 기반으로 Journey Map을 스킵합니다. 'add journey'로 답변하시면 언제든 다시 추가할 수 있습니다."

### 트리거 시 동작 (기본)

Journey Map 단계로 진입하기 전에 **왜** 필요한지를 인용하는 간결한 평가 메모를 출력하세요:

> "Persona가 완성되었습니다. Job이 [N] 단계([단계 A → 단계 B → ...])에 걸쳐 있어 — User Journey Map으로 진행합니다. 필요하지 않으시면 '-S3'로 답변하여 스킵하세요."

## 3. Optional 트리거 — Full Mode

| 단계 | 프레임워크 | 기본값 | 로직 |
|------|-----------|---------|-------|
| S3 | User Journey Map | **ON** | 위의 Persona-Journey 규칙(섹션 2) 참조. 단일 상호작용 지점 / 플로우 ≤2 단계 / 사용자가 명시적으로 스킵 요청 시에만 스킵 |
| S6 | April Dunford Positioning | OFF | 트리거 조건: (a) 신제품 출시 OR (b) 재포지셔닝 OR (c) 대상 독자에 Sales/BD/Marketing 포함 |
| S11 | PMF + GTM + Business Model + 가설 검증 계획 | OFF | 트리거 조건: (a) 제품이 시장에 출시되는 중 OR (b) 대상 독자가 경영진/Data Scientist OR (c) 사용자가 검증 계획을 명시적으로 요청 |

## 5. Phase 결정 포인트 출력 형식

**Optional 단계를 포함하는 각 Phase에 진입하기 전, AI는 반드시 어떤 Core/Optional 단계가 실행될지 그리고 그 이유를 나열하는 Phase 결정 포인트 블록을 출력해야 합니다.**

### 필수 형식

```
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━
🔀 Phase [N] 단계 결정

✅ Core(항상 실행): S[a], S[b]
🔵 Optional 평가:
  • S[x] [프레임워크명] (기본 ON):  [PROCEED / SKIP] — [이유]
  • S[y] [프레임워크명] (기본 OFF): [TRIGGER / SKIP] — [이유]

→ 이 phase는 [N]개 단계를 실행합니다
("+S[x]"로 강제 포함, "-S[y]"로 강제 스킵, 또는 그냥 계속 진행)
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━
```

기본 ON 단계(예: S3 Journey Map)의 경우, 조건이 유지될 때 **PROCEED**, 스킵 조건이 발동할 때 **SKIP**을 사용하세요.
기본 OFF 단계(예: S6 Positioning, S11 PMF/GTM)의 경우, 조건이 충족될 때 **TRIGGER**, 그렇지 않으면 **SKIP**을 사용하세요.

### 표시 시점

- 적어도 하나의 Optional 단계를 포함하는 각 Phase의 시작 시 한 번 표시
- Core 단계만 포함하는 Phase는 결정 포인트가 필요하지 않음(바로 진행)
- 표시 후, 사용자 응답을 기다림. 오버라이드가 아닌 응답(예: "ok", "계속", 또는 실질적인 콘텐츠)은 "AI의 결정을 수락"을 의미함

### 사용자 오버라이드 명령

| 사용자 입력 | 동작 |
|------------|----------|
| `+S[x]` 또는 "S[x] 추가" | 이전에 스킵된 Optional 단계를 강제 포함 |
| `-S[y]` 또는 "S[y] 스킵" | 이전에 트리거된 Optional 단계를 강제 스킵 |
| 실질적인 콘텐츠 / "계속" / Enter | AI의 평가를 수락하고 진행 |

## 6. Custom Mode — Persona-Journey 조건부 삽입

Custom Mode 프리셋(Lean / Standard / Comprehensive)은 고정된 단계 시퀀스를 가지지만, Persona 단계를 포함하는 모든 프리셋에는 Persona-Journey 번들링 규칙이 여전히 적용됩니다.

| 프리셋 | 기본 동작 | Persona 단계 이후 동작 |
|--------|------------------|----------------------------|
| **Lean** | Persona 단계 없음 | 해당 없음 |
| **Standard** | 8 고정 단계, S1 = Persona | S1 이후, AI는 섹션 2에 따라 Persona-Journey 평가를 실행합니다. 스킵 조건이 충족되지 **않으면**, AI는 Journey Map을 **S1.5로 능동적으로 삽입(9단계 실행이 됨)**하며 사용자는 `-journey`로 답변하여 되돌릴 수 있습니다. 스킵 조건이 충족되면, 조용히 스킵하고 최종 출력에서 공개합니다(섹션 7). |
| **Comprehensive** | 11 고정 단계, S2 = Persona, S3 = Journey Map (이미 포함됨) | AI는 간단한 "스킵 가능" 노트를 출력할 수 있습니다: "Journey Map은 기본 활성화되어 포함되어 있습니다. 상황이 매핑하기에 너무 단순하면 `-S3`로 답변하세요." 그렇지 않으면 정상적으로 진행합니다. |

이는 상황이 진정으로 단순할 때 Lean/Standard 사용자가 방해받지 않도록 하는 동시에, Journey Map의 *혜택을 받을 수 있는* 사용자에게 조용히 거부되지 않도록 보장합니다.

---

## 7. 최종 출력 공개

모드가 완료되면 최종 Product Spec Summary는 반드시 어떤 Optional 단계가 스킵되었는지 나열하고 한 번의 명령으로 다시 추가할 수 있는 경로를 제공해야 합니다. 예:

> "이번 실행에서 스킵된 Optional 단계: S6 (Positioning), S11 (PMF/GTM). 'add S6' 또는 'add S11'로 답변하여 채워 넣으세요."
