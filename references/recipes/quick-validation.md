# Recipe: Quick Validation

**When to suggest this:** the user wants a fast, one-page direction check before committing real effort to a full plan.

## Lens sequence

1. jtbd
2. pr-faq
3. success-metrics

The output is a one-page direction: the job to be done, the narrative of the solution, and how success will be measured. Jumping back to jtbd after the pr-faq reveals a gap is expected.

This is a suggested order, never forced. It is not a slash command; the meta-skill offers it in one line and proceeds on the user's own sequence if they prefer.
