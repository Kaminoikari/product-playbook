# Recipe: Feature Extension

**When to suggest this:** the user is adding a feature to an existing system and needs to weigh it against what is already built.

## Lens sequence

1. problem-framing (with the existing-system context named up front: current architecture, adjacent features, known constraints)
2. solution-prioritization
3. pre-mortem (focused on regression risk and compatibility with the existing system)
4. mvp-scoping

Jumping back to problem-framing after the pre-mortem surfaces a compatibility issue is expected.

This is a suggested order, never forced. It is not a slash command; the meta-skill offers it in one line and proceeds on the user's own sequence if they prefer.
